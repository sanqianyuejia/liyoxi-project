演练在两处跑通过：本机（macOS，arm64）；一个临时的 Linux Docker（容器里另起的 Docker，arm64），以普通用户跑，密钥文件的属主照清单改、照样核对。没有验的：服务器上的各步（`infra/bootstrap/README.md` 第 2–7 节）一步都没有做；systemd 单元、受限 SSH、sudoers、宿主机 nginx 的重载只有用例（系统命令桩掉）与 `nginx -t`；amd64 上的演练与 `stack-smoke.yml` 加了这一步之后在 CI 上的时长（超时 15 分钟）；境内节点能否直接拉库与 Redis 的官方镜像。内存上限是 ADR-041 的起始值，没有在那台机器上实测。

往后移交：W2-26 接 `node-step.sh`（`stage-assets` 时把 `static/` 挂进 gateway、`prune`、分开换 worker 与 api）；每日备份的包把 `backup-database-url` 挂给 worker 并接进 `loadEnv`；接第三方密钥的包往 `infra/deploy/secrets.manifest.json` 与 `node.yml` 各加一项。
